# Private podcast feed

Drop `.m4a` or `.mp3` files into `episodes/`, commit and push with GitHub Desktop,
and they show up as new episodes in Apple Podcasts on your iPhone a few minutes later.

- Feed address: `https://<your-github-username>.github.io/<this-repo-name>/feed.xml`
  (also shown on the site's home page)
- Show title, author and description: edit `podcast.json`
- Cover art: replace `cover.jpg` (square, 1400–3000 px)
- Episode titles come from the file names, so name files the way you want them to read.

Files here are public to anyone who has the exact address. Don't put anything private in this repo.
